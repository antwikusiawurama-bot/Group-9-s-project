## Project Components, Setup and Limitations

### 1. Dataset Generator

The **Dataset Generator** is responsible for creating the synthetic electricity network dataset used throughout the project. The generator is implemented in `dataset_generator.py` and produces the structured data required for data cleaning, exploratory data analysis, statistical analysis, visualisation and network analysis.

The generated and cleaned datasets include `substations_cleaned.csv` and `lines_cleaned.csv`, which contain information about substations and the transmission or distribution lines connecting them.

Supporting data-cleaning and analysis work is contained in the project notebooks and scripts, including `generate_dataset.ipynb`, `task_1_1_data_cleaning.ipynb`, `TASK 1.2.py`, `Task1.3`, and `task 2.3.py`.

### 2. GridCare-Lite

**GridCare-Lite** is the electricity network analysis component of the project. It uses the generated and cleaned substation and line datasets to perform exploratory data analysis, statistical analysis, visualisation and network analysis.

The system represents the electricity network as a graph in which substations act as nodes and electricity lines act as edges. It analyses important network characteristics such as connectivity, centrality, community structure and N-1 contingency scenarios to identify critical substations, important connections and potential vulnerabilities within the network.

### 3. ClinicCare-Lite

**ClinicCare-Lite** is a role-based web application designed to support administrative healthcare workflows for clinicians and patients.

The system allows users to register and log in securely according to their roles, while clinicians can manage administrative tasks, review patient submissions, communicate with patients and monitor engagement. Patients can access assigned tasks, submit required files, track their submission status and view relevant administrative information.

The application includes authentication, validation, secure password hashing, role-based access control, session management, file handling, messaging and responsive user interfaces.

**ClinicCare-Lite remains strictly administrative and non-diagnostic:** it does not interpret symptoms, diagnose medical conditions or recommend treatments.

Before running the project, ensure that Python 3 is installed on your computer.

Clone the project repository and navigate to the project folder:


## Reproducibility

The dataset generator was executed using `random.seed(42)` without modification.

This fixed random seed ensures that the synthetic dataset generated by `dataset_generator.py` is reproducible. Running the generator under the same conditions produces consistent results, allowing the data cleaning, exploratory data analysis, statistical analysis and network analysis to be replicated.

## Known Limitations

The project uses synthetically generated data and therefore may not capture every complexity, uncertainty or unexpected condition found in a real-world electricity network or healthcare environment.

The electricity network analysis is based on the generated substation and line data and should therefore be interpreted as an analytical prototype rather than a replacement for real-time power-system modelling.

The N-1 contingency analysis identifies potential network vulnerabilities based on the modelled network structure and does not include all physical factors that may affect an actual electricity grid.

The prototype applications use simplified data persistence and security controls suitable for an academic project but would require stronger database infrastructure, additional security measures, more extensive testing and production-level deployment controls for real-world use.

In addition, **ClinicCare-Lite is strictly an administrative and non-diagnostic system** and does not provide medical diagnosis, symptom interpretation, treatment recommendations or emergency medical decision-making.
